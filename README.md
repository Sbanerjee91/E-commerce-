# 🛒 E-Commerce Website

A modern, full-stack E-Commerce Website Template designed with separate experiences for Customers and Sellers.

The platform allows customers to browse products, search and filter items, manage their shopping cart, place orders, and track purchases. Sellers get a dedicated dashboard where they can add products, manage inventory, process orders, and monitor their store performance.

This project is designed as a reusable foundation for building a scalable online marketplace.

## ✨ Features
👤 Customer Features

🔐 Authentication
- User registration
- User login/logout
- Secure authentication
- Password management
- Profile management
  
🛍️ Product Browsing
- Browse products
- Product categories
- Product details
- Product images
- Product variants
- Product ratings and reviews
- Related products

🔎 Search & Filtering
- Search products

🛒 Shopping Cart
- Add products to cart
- Remove products
- Increase/decrease quantity
- View cart total
- Automatic price calculation
- Cart persistence

💳 Checkout
- Shipping address
- Billing information
- Order summary
- Payment integration
- Order confirmation
